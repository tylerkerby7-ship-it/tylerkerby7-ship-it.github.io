Privacy Policy

Last updated: November 5, 2026

Ultron is a personal assistant that runs entirely on its owner's own computer. It is used only by its owner.

What Google data Ultron uses

  • Gmail: reads message headers and contents when the owner asks about their email; creates drafts; sends email only after the owner confirms out loud or in writing.
  • Google Calendar: reads events, and adds or deletes events when the owner asks. Deleting always requires confirmation.

How it is stored and shared

  • The sign-in token is stored only on the owner's computer. No server run by anyone else receives it.
  • Email and calendar data is processed on the owner's computer to answer the owner's request and is not stored, sold, shared with third parties, or used for advertising.
  • If the owner chooses to use an optional cloud AI model, the text of that request (which may include email or calendar content) is sent to that AI provider only to generate the reply.
  • Ultron's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions, which also makes the stored token useless.

Contact

Questions: use the support email shown on the app's Google sign-in screen.
